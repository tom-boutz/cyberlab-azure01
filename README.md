# cyberlab-azure01
Cybersecurity Lab using Azure Microsoft Sentinel. Real threat detection and SIEM use case.

# the-idea
The whole point of this Lab is to understand what is needed to turn a simple Lab into something that is a progress towards a better "cyber-skill-set".

# the-lab
The lab will have images of what to do and how to do, making it easy to follow along. Beaware some parts will need to be done differently based on [year_posted] and the [year_you're_reading_it]. Some applications will be neeeded to have a "work around" if using legacy models, like old Macs and/or Windows.
